What it is

Fregoli is a web application an agent can rewrite while it is running. Instead of editing files and restarting the process, capabilities are Cordis plugins that are mounted and unmounted in a live Node process. The name comes from Leopoldo Fregoli (1867–1936): one performer, many appearances, no restart of the show.

On start you get a canvas on port 8080 and an assistant chat in the lower right. Chat goes to the Grok CLI over ACP when grok is on PATH, otherwise to an in-process stub. Grok receives an MCP server that lets it observe the page, load and unload plugins, highlight elements and wait for the user to click.

Status: the spec describes the first slice as implemented (web, assistant, Grok ACP, loader gate, page bridge, MCP tools). CI runs npm test on every push; tagged releases attach a source tarball. The CLI is always fregoli in full, never freg.

Key concepts

Cordis kernel

The kernel is Cordis (npm cordis). Every capability is a plugin, or “fiber”, that can be mounted and disposed at runtime.

Web plugin

HTTP on TCP 8080: the canvas, the assistant slot, a JSON API and the page bridge (DOM snapshot, highlight, user click).

Agent plugin

Spawns grok agent --always-approve stdio and speaks ACP. Falls back to a stub without grok. Unloading the plugin kills the child.

Assistant plugin

Lower-right chat panel. A separate plugin: replaceable and removable. fregoli --assistant forces the stock one for that start.

Loader gate

Mounts extra plugins from fregoli.json or POST /load. A plugin whose apply fails does not become ACTIVE and does not replace the canvas.

MCP tools for Grok

src/mcp.ts: list_plugins, load_plugin, unload_plugin, observe_page, highlight, wait_click, reload_page.

Getting started

Needs Node 22+. For a real agent, the Grok CLI on PATH (authenticated via Grok CLI login or XAI_API_KEY).

git clone https://github.com/pihme/fregoli.git
cd fregoli
npm ci
npx tsx src/cli.ts              # http://127.0.0.1:8080/
npx tsx src/cli.ts --assistant  # force the stock assistant UI
npx tsx src/cli.ts --version

Run the tests (the merge gate):

npm test

Container image (Hermetarium is a recommended habitat, not a requirement):

docker build -t fregoli:local .
docker run --rm -p 8080:8080 fregoli:local

Saved config lives in fregoli.json in the process working directory:

{ "assistant": true, "plugins": [] }

Full CLI and HTTP reference: USAGE.md.
