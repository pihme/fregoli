Timeline

How Fregoli has developed so far, newest first.

September 2026

Fregoli started on 25 September with a first commit containing the spec and the PolyForm Noncommercial license; the GitHub repository was created the same evening. Within half an hour the first slice was in place: a Node and Cordis CLI with web and assistant plugins, a stub agent, a plugin loader, and the Grok CLI connected over ACP. The page bridge, a Hermetarium inhabitant image and the MCP tools for observing the page and loading plugins followed shortly after. v0.1.0 came out at 20:47 with docs, CI and automated release tagging, and five more releases followed that night: v0.2.0 added the chat-style assistant panel and plugin list/unload, v0.3.0 made reload_page keep the assistant open with its history, and v0.3.1 shipped the welcome canvas. On 26 September a documentation pass brought the README, spec and usage guide in line with the code, and this website went live on GitHub Pages, gaining a sidebar layout, an architecture diagram and this timeline later the same day.
